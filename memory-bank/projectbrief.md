# Project Brief - PachiPon

PachiPonは、Pyxelを使用したレトロスタイルのゲームプロジェクトです。

## 目標
- 短いターン数で最終ボスを撃破する。
- プレイヤーの行動、イベント、戦闘などをダイスロールや各種システムコマンドで管理する。

## 要件
- イベントポイントにおける各種ランダムイベント（SAFETY、NORMAL、GAMBLE）の実装。
- 武器、魔法、戦闘システム。
- 食糧消費や移動コストによるリソース管理。

## スコープ
- イベント定義マスタ（`event_master.json`）の作成。
- イベント制御、およびコマンドパターンの適用によるゲームシステム構築。
